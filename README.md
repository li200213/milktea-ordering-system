# 🥤 奶茶自助点单系统 (Milk Tea Ordering System)

本项目是一个基于 **JavaWeb (JSP + Servlet)** 技术栈开发的奶茶自助点单系统。项目采用标准的 **MVC 三层架构**，实现了从前台用户点单到后台管理员管理的完整业务流程。

旨在解决线下门店排队时间长、沟通成本高的问题，实现线上线下融合的点单体验。

## ✨ 功能模块 (Features)

系统分为 **前台点单系统** (面向顾客) 和 **后台管理系统** (面向管理员) 两大部分。

### 📱 前台用户端
- **用户认证**：支持用户注册、登录。
- **商品浏览**：
  - 首页轮播图推荐。
  - 按类目（如奶茶、果茶）筛选商品。
  - 关键词搜索商品。
- **商品详情**：查看价格、库存、描述，支持选择 **甜度** (全糖/7分/5分等)、**温度** 和 **小料**。
- **购物车**：添加商品、修改数量、删除商品、一键清空。
- **订单管理**：提交订单、选择支付方式、查看历史订单状态。

### 💻 后台管理端
- **商品管理**：
  - 商品的增删改查。
  - 设置商品详情图、库存、价格。
  - **推荐管理**：将商品加入/移出首页推荐栏。
- **订单管理**：
  - 查看所有订单列表。
  - 订单状态流转：已付款 -> 制作中 -> 已完成。
  - 删除历史订单。
- **类目管理**：管理饮品的分类（增删改）。
- **客户管理**：查看注册用户信息，支持重置用户密码或删除用户。

## 💾 数据库设计 (Database)

项目共包含 9 张数据表：

1.  **user**: 用户表 (存储前台用户及管理员信息)
2.  **goods**: 商品表 (名称、图片、价格、库存等)
3.  **type**: 商品-类型关联表
4.  **type_item**: 商品类型表 (类目名称)
5.  **ingredients**: 小料表 (珍珠、椰果等)
6.  **temperature**: 温度表 (冷/热/常温)
7.  **recommend**: 推荐栏商品表
8.  **cart**: 购物车表 (存储用户未下单的商品及规格)
9.  **order**: 订单表 (订单状态、总价、支付方式等)
